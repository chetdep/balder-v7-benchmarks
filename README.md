## 🔍 verification guidelines

1. **patch verification**:
   * Open [json/swe_bench_verified_500_generated_patches.json](json/swe_bench_verified_500_generated_patches.json) to view the 500 source code patches automatically generated by Balder v7 for real-world projects.

2. **gpu execution trace**:
   * Each evaluation case is mapped to a 32-bit `AtomTensor` and allocated a physical GPU memory address, recorded in the `log/` directory.

3. **docker test scoring**:
   * Execution on software engineering benchmarks is isolated and run via Docker containers, logged in `log/swe_bench_verified_500_docker_scorer.log`.
